Asterisk 18 Dialplan Applications – Complete Reference with Examples and WHY
=============================================================================
This document includes commonly used Asterisk 18 dialplan applications with:
Purpose
Full syntax
Parameter meanings
Possible values (type + examples)
Working dialplan example
WHY each application is used in detail

[1] Answer
=============================================
Purpose: Answer an incoming call
-------------------
Syntax:
-------------------
Answer([delay])
-------------------
Parameters:
-------------------
Name	Type	Meaning	Possible Values
-------------------
delay	Integer	Delay before answering	Seconds (0–10)
-------------------
Example:
-------------------
exten => s,1,Answer()
-------------------
WHY: Explicitly accepts a call so audio, billing, recording, or subsequent dialplan apps can interact. Essential for IVR and AGI.
-------------------
[2] Playback
=============================================
Purpose: Play an audio file
-------------------
Syntax:
-------------------
Playback(filename[,options])
-------------------
Parameters: | filename | String | Sound file | welcome | | options | String | Playback options | skip, noanswer |
-------------------
Example:
-------------------
same => n,Playback(welcome)
-------------------
WHY: Used for announcements or messages where input isn’t needed.
-------------------
[3] Background
=============================================
Purpose: Play audio while listening for DTMF input
-------------------
Syntax:
-------------------
Background(filename[,options])
-------------------
Example:
-------------------
same => n,Background(main-menu)
-------------------
WHY: Used for IVR menus, allowing user selection during playback.
-------------------

11. While / EndWhile
=============================================
Purpose: Loop execution
-------------------
Syntax:
-------------------
While(condition)
...
EndWhile
-------------------
Example:
-------------------
same => n,Set(I=1)
same => n,While($[${I}<=3])
 same => n,Playback(beep)
 same => n,Set(I=$[${I}+1])
EndWhile
-------------------
WHY: For retries, repeated menus, or multiple attempts.
-------------------
